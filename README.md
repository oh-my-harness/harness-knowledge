## 使用指南

### 作为 Obsidian Vault 使用
1. 在 Obsidian 中打开此目录作为 Vault
2. 使用 `[[wikilink]]` 进行双向链接导航
3. 使用 `#tag` 进行标签检索
4. 通过图谱视图查看知识关联

- 保持 frontmatter 元数据完整
- 善用双向链接建立知识关联
- 重大变更前更新 `_index.md`
