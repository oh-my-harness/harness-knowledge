# 🤖 AI Coding Best Practices

> AI 辅助编程的工程实践与方法论


## 核心原则

1. **人机协作** — AI 是工具，开发者保持决策权
2. **增量迭代** — 小步提交，频繁验证
3. **上下文即质量** — 输入的上下文质量决定输出质量
4. **验证优先** — 始终验证 AI 生成代码的正确性
